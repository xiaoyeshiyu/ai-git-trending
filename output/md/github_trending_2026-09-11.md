### ✨ vastsa/PI-Desktop (1457★)

> **一句话**：把本地代码仓库、AI Agent 对话、模型配置、文件修改审查和插件扩展集中到一个可跨平台运行的桌面工作区中。

- **它是什么**：PI-Desktop 是一款基于 Electron 的本地优先 AI 编程桌面应用，底层使用 Rust 主机核心和 pi Agent Harness 驱动 Agent。用户可以打开本地项目，连接 OpenAI、Anthropic、Ollama、LM Studio 或兼容 OpenAI API 的模型，让 Agent 读取文件、修改代码、运行命令，并在 Review 面板中检查变更。它还支持 Agent、Plan、Goal 三种工作模式，以及 Skills、MCP、Subagents 和可安装插件。

- **能解决什么痛点**：开发者不必在终端、编辑器插件和托管式 AI 服务之间切换，也不需要把项目迁移到特定编辑器中才能使用 Agent。对于需要控制权限和审查改动的场景，文件编辑、命令执行等特权操作会经过权限层，模型请求则直接发送到用户配置的服务商。

- **适合谁用**：希望在本地仓库中使用多个云端或本地模型，并统一管理长时间编码会话的个人开发者和小型研发团队。也适合需要通过 MCP、Subagents 或插件扩展 Agent 能力，同时关注凭据和项目数据本地存储的技术用户。

- **怎么上手**：从 [GitHub Releases](https://github.com/vastsa/PI-Desktop/releases/latest) 下载对应 macOS、Windows 或 Linux 的安装包，启动后进入 `Settings → Model configuration` 配置模型，再从侧边栏打开本地项目；文档未提供快速上手示例。
