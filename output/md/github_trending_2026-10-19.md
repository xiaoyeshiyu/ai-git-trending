### ✨ MadsLorentzen/ai-job-search (33689★)

> **一句话**：把 Claude Code 变成一条在本机运行的求职流水线，自动筛岗位、评估匹配度、改简历、写求职信，还能继续准备面试。

- **它是什么**：这是一个围绕 Claude Code 设计的求职应用框架，核心不是单次生成文案，而是把 `/setup`、`/scrape`、`/apply`、`/interview` 这些步骤串成完整流程。它会读取你的个人资料和文档，抓取多个招聘平台的岗位，按 fit 评分排序，再为选中的岗位生成定制化简历、求职信和面试准备材料。
- **能解决什么痛点**：一是重复性投递太耗时，尤其是每个岗位都要重新匹配经历、改简历、写 cover letter。二是不同招聘网站信息杂乱、字段不一致，手工筛选和比对很容易漏掉合适岗位或看错截止时间、地点、薪资等关键信息。
- **适合谁用**：适合正在高频投递的求职者，尤其是愿意把材料整理成结构化文件的人。也适合做跨平台岗位聚合、简历定制和面试准备自动化的 Python 用户，或者想把 Claude Code 接进自己工作流的高级使用者。
- **怎么上手**：README 给出的最小路径是先装好 Claude Code、Python 3.10+、Bun 和 LaTeX，然后在仓库里运行 `claude` 再执行 `/setup`，之后用 `/scrape` 搜索岗位、用 `/apply ` 处理具体职位。
- **可以用在哪些场景**：适合批量浏览多个招聘站点，先做初筛再人工确认重点岗位。适合把同一份基础履历按不同岗位方向生成定制申请材料。也适合在面试前自动整理岗位、公司和历史申请记录，准备针对性的复盘材料。
- **技术看点**：项目把求职流程拆成多个 Claude Code 命令，外层是 Python 工作流，岗位搜索又依赖 Bun 生态里的独立 CLI 工具。README 里能看出它对招聘站点解析、职位去重、fit 评分、LaTeX 简历生成、ATS 可读性检查这些环节都做了工程化处理。
- **近期动向与发展方向**：最近 20 条提交明显偏活跃，重点集中在修复各招聘站点解析兼容性、缓存公司调研结果、处理门户 CLI 参数校验、调整排名字段和 HTML 报告逻辑。近期还合入了 v1.6.0 发布与 CI/LaTeX 冒烟测试，说明项目正从“能用”继续往“更稳、更可维护”演进。
- **同类对比**：README 没有给出明确竞品。它更像是把“求职自动化”做成可执行工作流，而不是单纯的简历生成器或职位爬虫。
- **注意事项**：上手门槛不低，依赖 Claude Code、Bun 和完整 LaTeX 环境，安装链路比普通 Python 项目长。项目更新很活跃，说明维护跟得上，但也意味着命令、门户适配和工作流细节可能会继续变化；另外 README 明确提到公共 fork 会暴露个人资料，私用场景要特别注意仓库可见性和数据落盘位置。
