✨ mksglu/context-mode (20592★)

一句话：它把 AI 编码代理最容易“吃掉上下文”的工具输出、会话记忆和路由策略统一管起来，让模型少读原始噪音、多保留关键状态，适合长会话里持续做代码工作的场景。

  • 它是什么：Context Mode 是一个面向 AI 编码代理的 MCP 服务和插件体系，核心目标不是“多给模型工具”，而是把工具输出先隔离、压缩，再按需检索回上下文。README 里强调它通过 sandbox 工具减少原始输出进入上下文窗口，同时把文件编辑、git 操作、任务、错误和用户决策持久化到 SQLite，再用 FTS5 + BM25 做检索，避免会话压缩后丢失工作状态。

✨ jo-inc/camofox-browser (9376★)

一句话：它把一套带反检测能力的 Firefox 浏览器封装成给 AI agent 调用的服务，让程序可以像真人浏览器一样打开网页、拿到可点击的元素引用、执行登录和抓取，同时尽量绕过 Cloudflare 和常见 bot 检测。

  • 它是什么：这是一个基于 Camoufox 的浏览器服务层，核心不是“再造一个浏览器”，而是把浏览器能力包装成适合 agent 调用的 REST API。README 里明确强调了三件事：反检测、稳定交互引用、以及面向自动化的结构化输出，例如 accessibility snapshot、e1/e2 这种元素引用、截图和 OpenAPI 文档。
  • 能解决什么痛点：一是 Playwright / headless Chrome 在站点风控下频繁被拦，导致脚本刚跑到登录页就失效；二是大页面抓取时原始 HTML 太大、上下文太吵，给 LLM 喂数据成本高且不稳定。它试图把“能打开网页”变成“能持续完成网页任务”，包括 cookie 注入、会话持久化、VNC 交互登录这些现实需求。
  • 适合谁用：做浏览器自动化的 AI agent 工程师；需要稳定采集网页数据、但经常遇到反爬和指纹检测的数据工程师；还有在做登录后流程自动化、站点操作脚本或 RPA 的前端/后端开发者。
  • 怎么上手：最小方式是直接运行 npm 包：npx @askjo/camofox-browser。如果从源码启动，README 给出的最短路径是 git clone https://github.com/jo-inc/camofox-browser && cd camofox-browser && npm install && npm start。
  • 可以用在哪些场景：自动化登录 LinkedIn、Amazon、Google 这类会主动识别脚本环境的网站；让 AI agent 代替人工完成网页检索、下单、表单填写和截图取证；在需要长期运行的抓取任务里，用会话持久化和 cookie 导入减少重复登录。
  • 技术看点：它的关键点在于 Camoufox 在 C++ 层做指纹伪装，而不是靠前端脚本补丁，这比常见 stealth plugin 更贴近底层。另一个值得注意的是它不是单纯的浏览器启动器，而是把 accessibility snapshot、稳定元素引用、结构化抽取、下载捕获和 trace 这些能力一起做成了 agent 友好的接口层。
  • 近期动向与发展方向：最近提交明显集中在 1.14.0 发布前后的稳定性和兼容性修补上，包括 Node 24 支持、ARM64 Docker/runtime 修复、导航健康检查和会话恢复、VNC 清理、依赖审计、以及 MCP 可靠性问题处理。同时也加入了“可选的交互式桌面浏览器”这类新能力，说明项目一边补生产环境细节，一边扩展更强的人类介入操作方式，整体处于活跃维护状态。
