✨ Gitlawb/openclaude (31187★)

一句话：在终端里统一调用 OpenAI、Gemini、GitHub Models、Ollama 等云端和本地模型，并提供文件操作、命令执行、MCP、Agent、流式输出等编码助手能力。

  • 它是什么：OpenClaude 是一个开源的编码 Agent CLI，主打“一个终端工作流接入多种 LLM 后端”。它支持 OpenAI 兼容 API、Gemini、GitHub Models、Codex OAuth、Ollama、Atomic Chat 等提供方，同时内置提示词、工具调用、子 Agent、任务、MCP、斜杠命令和流式输出。README 还提到它带有 VS Code 扩展，可用于从编辑器侧启动和配合主题集成。

  • 能解决什么痛点：开发者如果同时试用云端模型、本地 Ollama 模型和不同 OpenAI 兼容网关，通常要切换多套 CLI、环境变量和配置方式；OpenClaude 用 /provider 和保存的 profile 把这些入口收拢到一个终端里。另一个痛点是长任务执行，项目提供 openclaude --bg、openclaude logs、openclaude kill 等后台会话能力，适合把“修测试”“重构某模块”这类任务丢到本地子进程中跟踪。

  • 适合谁用：适合频繁在终端中使用 AI 编码助手、并且想在 OpenAI、Gemini、Ollama、GitHub Models 等后端之间切换的全栈或后端开发者。也适合在公司内网、自建模型网关或本地模型环境中，需要保留 CLI 工作流的工程团队。

  • 怎么上手：npm install -g @gitlawb/openclaude@latest && openclaude

  • 可以用在哪些场景：用本地 Ollama 跑代码问答和小规模重构，同时保留和云端模型相同的终端交互方式；在多模型网关环境中，通过 /provider 管理不同模型提供方的配置和凭据；把较长的修复或重构请求放到后台会话中执行，再用 openclaude logs -f 查看进度。

  • 技术看点：项目使用 TypeScript 编写，运行时要求 Node.js >=22.0.0，面向 npm 全局安装和 CLI 分发。设计重点在 provider 抽象、OpenAI shim、MCP/工具调用、后台 session 管理和终端 TUI 输入处理，近期提交也显示这些模块是维护重点。

  • 近期动向与发展方向：最近 20 条提交中既有 0.29.0、0.29.1、0.30.0 连续发布，也有 provider、settings、background session、TUI、openai-shim、prompt cache 等多个核心路径的修复，说明项目处于高频迭代期。新增方向集中在更多模型/网关支持，例如 OpenRouter、OpenGateway 的实时模型列表，以及 LLMTR hybrid gateway；同时也在补单元测试、收紧安全校验，比如 marketplace hostPattern 防仿冒域名、权限规则验证和 attribution 处理。

✨ jingyaogong/minimind (55891★)

一句话：MiniMind 把一个约 64M 参数语言模型从 tokenizer、预训练、SFT、LoRA 到 RLHF/RLAIF 的训练链路完整摊开，让个人开发者用普通 GPU 也能从零复现一个小型 LLM。

  • 它是什么：这是一个面向 LLM 学习与复现的 Python/PyTorch 项目，目标是在低成本、短时间内训练出 MiniMind 系列超小语言模型。README 中明确提供了 Dense、MoE、Tokenizer、数据清洗、预训练、监督微调、LoRA、DPO、PPO、GRPO、CISPO、Tool Use、Agentic RL、模型蒸馏等完整流程代码。项目还提供已发布模型、开源数据、CLI 推理、Streamlit WebUI、OpenAI API 兼容服务端，以及 Hugging Face / ModelScope / ollama / vllm 等生态接入方式。
  • 能解决什么痛点：很多开发者想理解 LLM 训练细节，但直接看大模型工程成本高、依赖框架抽象多，难以看到 tokenizer、训练循环、强化学习对齐等底层实现。MiniMind 用 26M、64M、104M、MoE 等小规模模型，把从零训练、微调、推理部署的全流程压到个人 GPU 可复现的范围内。
  • 适合谁用：适合想系统学习 LLM 训练流程的 Python/PyTorch 开发者、AI 入门研究者，以及需要用小模型验证训练算法、数据流程、Tool Call 或 RLAIF 实验的工程师。也适合有单张消费级 GPU、希望自己跑通完整大模型训练链路的个人开发者。
  • 怎么上手：git clone --depth 1 https://github.com/jingyaogong/minimind && cd minimind && pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple
