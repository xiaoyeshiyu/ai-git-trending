✨ JetBrains/go-modern-guidelines (2093★)

一句话：它把 Go 1.0 至 Go 1.27 的现代语法和标准库用法整理成可被 AI 编程代理自动调用的技能，让代理根据项目的 go.mod 版本生成更符合当前 Go 生态的代码。

  • 它是什么：这是 JetBrains 维护的一套面向 AI coding agent 的 Modern Go 指南，不是传统的代码库或独立静态分析器。代理读取项目的 Go 版本后，会优先使用对应版本可用的现代写法，例如用 max、slices.Contains、cmp.Or、new(42) 和 errors.AsType[T] 替代较旧的实现方式。指南覆盖 Go 1.0 至 Go 1.27，并覆盖 modernize analyzer 关注的多数现代化改写场景。
  • 能解决什么痛点：AI 代理容易受训练数据滞后影响，继续生成旧版 Go 代码，例如手写循环替代 slices.Contains，或用冗长的条件判断替代新标准库 API。即使模型知道新特性，也可能因为旧写法在代码样本中出现频率更高而优先采用，项目通过显式规则纠正这类偏差。
  • 适合谁用：使用 Junie、Claude Code、Codex、Cursor 或 OpenCode 等 AI 编程代理开发 Go 项目的团队。尤其适合需要同时维护多个 Go 版本、希望新代码遵循当前语言和标准库惯用法的 Go 开发者。
  • 怎么上手：其他支持 skills.sh 的代理可以直接执行 npx skills add JetBrains/go-modern-guidelines 安装；也可以使用 --skill use-modern-go 只安装这项技能。使用 Junie、Claude Code、Codex 或 Cursor 时，则按照 README 提供的 marketplace/plugin 命令安装对应插件。
  • 可以用在哪些场景：
  • AI 代理为已有 Go 服务补充接口、错误处理和集合操作时，自动遵循项目 go.mod 声明的 Go 版本。
  • 使用 Go 1.23 及以上版本重构旧代码，将手写循环、冗余条件判断替换为现代语言和标准库写法。
