  • 它是什么：Codex CLI 是 OpenAI 用 Rust 编写的本地编码代理，运行在开发者的计算机和终端中。它支持通过 ChatGPT 账号或 API Key 使用，并围绕命令执行、沙箱权限、MCP、插件及代码库上下文处理等能力完成开发任务。项目还提供 VS Code、Cursor、Windsurf 集成，以及 codex app 桌面应用和 Codex Web 等使用入口。

  • 通过 MCP、插件以及浏览器或计算机操作能力，把代码代理接入内部工具、开发环境和需要网页交互的任务流程。
